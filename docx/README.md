## 文档维护约定

- 新文档放在本目录，并加入对应分类；根目录保留项目首页和开发约定。
- 文档之间使用同目录相对链接，引用代码时使用 `../backend/`、`../frontend/` 等仓库路径。
- 更新记录只写入 [version.md](version.md)，已发布版本与未发布变更分开维护。
- 区分设计、已实现功能和已执行验证；尚未完成的能力明确标记。
