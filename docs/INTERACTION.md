# 离线指令解析与受控执行

v1.0.5在v1.0.4基础上增加离线规则。固定命令优先，失败的`/`命令不会退回自然语言猜测；其余文本仅匹配完整的有界句式。没有网络、模型或数据库依赖，不支持的描述返回未识别，不会自动调用AI。

## 支持的表达

- `查询一下鼠标还有多少库存。`、`查询鼠标库存`、`鼠标还有多少库存？`，可加「请」「帮我」。
- `查询采购订单`或`查询采购订单 PO-单号`，最多返回当前授权范围内20条。
- `登记采购20个鼠标，每个35元。`，缺失供应商和币种，进入待补充请求。
- `采购2.5件"Mouse A"，单价12.50元，供应商="Supplier A"，币种=CNY。`，使用单商品、显式供应商与币种。
- 固定命令仍可使用，新增可选`单位=个`。普通Web表单不填写单位时沿用商品基础单位。

商品/供应商名称、ID或编码只由后续业务服务按当前可见字段唯一解析；解析器不从数据库猜实体。引号包围的名称作为一个字面实体；未引号包围的「和/及/与/或」等连接词及多动作文本拒绝。仅支持阿拉伯十进制数字，不转换中文数词、包装单位、汇率或税额。

数量保留4位、单价2位上限，继续使用Decimal规则。自然语言中的单位必须保留进请求payload，完整预览和确认时要求商品unit当前可读且完全相同。`2箱/每个`语义不一致拒绝；`公斤`与`千克`不自动视为同义，商品为piece时不能静默把「个」换过去。「元」不代表默认CNY，币种必须明确提供。

## Web和消息边界

协议无关的`erp.intent`定义BusinessIntent与固定命令；`erp.local_parser`输出相同operation/resource/arguments/references/confidence/parser_source。`erp.onebot.intent`保留兼容导入。confidence仅为确定规则的来源分数，不代表业务授权或允许执行。

Web操作工作台新增「用一句话开始」：识别 → 展示结构化结果 → 明确执行授权查询或生成待确认请求 → 原有业务预览/密码确认。编辑描述立即丢弃旧识别与查询结果；每次动作由后端重新解析，客户端不能提供角色、工具名称或可信授权结果。查询复用Web/OneBot的SQL范围与字段投影；创建复用持久化MessageOperation服务，没有直接创建订单的新通道。

消息入口仍要求受信实例、有效绑定、bindings.use和业务策略；群聊无业务回复或执行。重复事件沿用收件箱去重。采购描述仅创建待补充/待确认请求，补充、取消、超时及Web密码确认规则保持不变。

## 解析请求的数据与审计

解析部分无需修改原数据库结构：已有JSON payload新增可选unit白名单键，旧请求保持可读；本版本投递队列使用独立新迁移，见DELIVERY.md。HTTP输入最多4096字符、拒绝额外键；本地自然语言拒绝换行与控制字符。原始描述、身份信息、密码和外部模型配置不会写入审计，仅记录现有路由/操作状态和安全元数据。解析本身只生成惰性结果，除审计外不写业务表。

本阶段不支持自由自然语言补充、多商品描述、主动OneBot连接、AI回退或通用审批。无法识别时继续使用固定命令/表单，不对用户进行猜选或伪成功。
