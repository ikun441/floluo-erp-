# Changelog

从v1.0.4起，版本更新日志统一维护在 [docx/version.md](../docx/version.md)。下文保留已发布版本历史。

## 1.0.3 — 消息接入开发版（2026-10-21）

- 新增独立OneBot V11反向Universal WebSocket，实例/Bearer/bot身份校验、帧限制、实例停用和令牌轮换；不存储令牌原文。
- 新增Web密码复核的5分钟单次绑定挑战、指定QQ与实例、绑定撤销、持久化收件箱和事务审计；重复消息不重复执行，同键不同载荷拒绝。
- 新增固定命令、受控私聊采购/库存查询，复用Web权限、关联范围和字段投影；群聊不回复，消息写入仍要求Web操作。
- 接入用户提供的原始Q版Logo，覆盖登录、侧栏、浏览器图标与README，并补齐standalone/Docker静态资源复制。
- 新增真实API消息管理界面；DSH超时候选由Codex审查接管，补充敏感值清除和隐藏字段保护。
- 修正需要审批的读取在Web与消息上的过滤；新增独立迁移、收件箱防修改和失败回滚审计。
- 全套PostgreSQL/SQLite回归140 passed、5 skipped；Chromium7 passed；类型/格式/生产构建与迁移一致性检查通过。
- 正向WebSocket、多轮确认、AI、消息写入和真实QQ/生产部署验收仍待后续阶段。

## 1.0.2 — 开发快照（2026-10-20）

- 完成采购MVP：真实草稿/明细、显式提交、独立审批、未收货取消、分批入库、库存余额/流水和收货查询，Web与API共用业务服务。
- 新增用户隔离的收货幂等、超收/状态/版本校验、库存行锁、余额上限、金额精度检查、事务outbox；重放重新授权和投影。
- 新增显式币种/无税模式/独立审批配置，修改仅覆盖已提交字段；规则停用后拒绝新审批与入库。
- 增加关联SQL权限过滤、金额联动脱敏、隐藏ID分页保护，以及422/500失败审计；数据库异常不记录参数。
- 浏览器验收包含双账号审批和真实入库；修复下拉框标签可访问性、菜单滚动、配置复选框布局。通用审批工作流、OneBot、AI和销售报表仍待后续阶段。
- 统一更新前后端、健康探针、登录展示、测试工具包与锁文件的当前版本，创建v1.0.2开发标签。

## 1.0.0 — 开发中（2026-10-20）

- 创建架构与数据库设计、统一权限模型、OneBot/AI状态机、AGENTS和分阶段实施记录。
- 实现身份、组织、角色、版本化策略、范围与字段授权、审计及商品基础资料API。

- 通过真实PostgreSQL测试定位并修复审计时区问题；真实浏览器定位并修复登录缓存刷新问题。
- 提供Compose、Nginx、随机密码初始化及独立测试运行器。部署验收与后续业务阶段尚未完成，不发布正式release。

- Phase 2资料基础：分类树、供应商、仓库及商品分类关联，连接真实CRUD和统一权限，权限矩阵使用后端资源注册表。

- 新增v2审计变更摘要，兼容旧链；存在v2记录或新业务数据时拒绝破坏性降级。
- 修复独立启动时Alembic迁移目录依赖当前工作目录的问题。
- 本切片实际测试：PostgreSQL/SQLite套件80 passed、2 skipped；Chromium 5 passed；数量金额边界数据由Harness生成并经Codex接手审查验证。
