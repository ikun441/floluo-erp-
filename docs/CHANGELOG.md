# Changelog

## 1.0.0 — 开发中（2026-10-20）

- 创建架构与数据库设计、统一权限模型、OneBot/AI状态机、AGENTS和分阶段实施记录。
- 实现身份、组织、角色、版本化策略、范围与字段授权、审计及商品基础资料API。
- 新增Next.js真实管理入口、权限矩阵和模拟器。
- 登录页加入Three.js玻璃雕塑、轨道粒子、空间视差、Motion分层入场及验证反馈；提供暂停、减少动态效果和无WebGL降级。
- 通过真实PostgreSQL测试定位并修复审计时区问题；真实浏览器定位并修复登录缓存刷新问题。
- 提供Compose、Nginx、随机密码初始化及独立测试运行器。部署验收与后续业务阶段尚未完成，不发布正式release。
- 首次成功推送GitHub并核对远端main提交一致。
- Phase 2资料基础：分类树、供应商、仓库及商品分类关联，连接真实CRUD和统一权限，权限矩阵使用后端资源注册表。
- 新迁移预留采购/收货/库存/幂等/outbox数据关系与安全默认配置；相关业务API尚未开放。
- 新增v2审计变更摘要，兼容旧链；存在v2记录或新业务数据时拒绝破坏性降级。
- 修复独立启动时Alembic迁移目录依赖当前工作目录的问题。
- 本切片实际测试：PostgreSQL/SQLite套件80 passed、2 skipped；Chromium 5 passed；数量金额边界数据由Harness生成并经Codex接手审查验证。
