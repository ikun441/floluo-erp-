# 分阶段实施与验证

版本 1.0.0 为当前开发版本，非完整功能 release。

- Phase 0：模块边界、数据库关系、权限模型、消息/AI 状态机、API 规范、AGENTS。
- Phase 1：认证、组织、角色、策略版本、权限模拟与真实 Web 管理切片；默认拒绝的商品资料端点用于验证统一边界。
- Phase 2：商品分类/供应商、采购单/入库/流水与并发库存闭环。
- Phase 3：OneBot 双向连接、绑定、去重、离线命令、确认。
- Phase 4：可选 AI、严格意图 schema、受控工具、多轮状态。
- Phase 5：审批工作流、高级权限 UI、冲突分析与审计锚定。
- Phase 6：销售、报表、备份恢复演练、性能优化、上线检查。
