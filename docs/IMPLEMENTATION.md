# 实施与验证记录

当前版本v1.0.5，版本更新日志统一维护在[docx/version.md](../docx/version.md)。本文件记录真实实现与验证边界，不代表生产部署已验收。

## 已实现

保留Phase 0架构、Phase 1身份/组织/默认拒绝权限/策略模拟/审计、Phase 2采购草稿/独立审批/分批入库/库存流水，以及反向OneBot、单次绑定、消息去重、采购请求工作台和用户原始Logo。

v1.0.5增加协议无关的固定/本地规则分层解析，支持库存查询、采购订单查询和单商品采购描述。Web先识别并显示参数，再执行授权查询或生成请求；消息私聊共用同一应用服务。单位必须与当前可读商品unit一致，不猜币种、供应商或包装换算，不自动调用AI。

新增MessageDelivery持久化受限回复recipe，与收件箱/请求同事务；重试重新授权/投影，不重执行业务命令。最长5分钟、最多3次、每实例1000条非终态，终态清空recipe。当前echo/连接UUID与ok/整数0回执匹配才表示API成功；超时、失败和重连均按约束接续，无法保证回复恰好一次。

新增OneBotConnection租约、配置版本和连接UUID隔离，支持断线回收、异常退出后90秒失效和旧连接隔离。消息页提供真实连接与回复监控、状态筛选/分页。监控仅read，字段和实例关系受统一权限控制，旧角色不自动授权。

新增ad9e8f7a6b5c迁移，旧迁移不可变；新表约束快照配对、尝试次数、状态与完成时间，存在历史拒绝破坏性降级。升级需停止旧后端后迁移，不能混跑旧新发送器。
