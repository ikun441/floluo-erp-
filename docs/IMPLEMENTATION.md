新增8b7a6c5d4e3f迁移，不修改已发布迁移。收件箱有数据库防修改约束，有实例/绑定/挑战/去重数据时拒绝破坏性降级。旧策略不会自动增加新资源权限。修正requires_approval读取：SQL范围与详情投影均拒绝等待审批的记录；通用审批回执仍待后续实现。
